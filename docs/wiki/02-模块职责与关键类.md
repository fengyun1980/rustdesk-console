# 02 — 模块职责与关键类

所有 feature modules 位于 `src/modules/`，按领域划分为 **认证身份、业务核心、设置辅助、平台运维** 四大类。每个模块内部遵循 NestJS 约定：

```
<module>/
├── <name>.module.ts        # Module 装饰器，导入/导出依赖
├── <name>.controller.ts    # REST 路由
├── services/               # 业务逻辑（可导出）
├── entities/               # TypeORM Entity
├── dto/                    # class-validator DTO
├── guards/                 # 可选 Guard
├── decorators/             # 可选 Decorator
├── interceptors/           # 可选 Interceptor
├── strategies/             # 可选 Passport Strategy
└── *.spec.ts               # Jest 测试
```
